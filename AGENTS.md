# Agents Configuration

This file contains agent-specific instructions for the TFDTRONIC Electronics eCommerce project.

## Project Type

- **Framework**: Next.js 15 + Node.js/Express
- **Language**: TypeScript (Frontend), JavaScript (Backend)
- **Database**: MySQL with Prisma ORM
- **Styling**: Tailwind CSS

## Key Directories

| Directory | Purpose |
|-----------|---------|
| `app/` | Next.js App Router pages |
| `components/` | React components |
| `server/` | Express.js backend API |
| `prisma/` | Database schema |
| `lib/` | Utilities and libraries |

## Important Rules

1. Follow the coding conventions in `CLAUDE.md`
2. Always use TypeScript for frontend code
3. Use Prisma for all database operations
4. Follow RESTful API conventions
5. Write meaningful commit messages
