# Recent Change Notes

Tu thu muc nay, moi lan truoc khi sua code se tao mot file `.md` rieng de ghi ro noi dung thay doi.

Quy tac dat ten file:

```txt
YYYY-MM-DD-short-change-title.md
```

Moi file thay doi nen co cac muc:

```md
# Ten thay doi

## Van de
- Mo ta loi/hien tuong dang gap.

## Nguyen nhan du kien
- Ghi nhan root cause hoac gia thuyet can kiem tra.

## Pham vi sua
- Danh sach file/module du kien bi anh huong.

## Huong xu ly
- Cach sua du kien truoc khi thuc hien.

## Kiem thu
- Cac lenh hoac flow can test sau khi sua.

## Ket qua
- Cap nhat sau khi sua xong: da thay doi gi, test nao da chay, con rui ro nao.
```

Ghi chu: file `.md` phai duoc tao truoc khi thuc hien thay doi code cho task tuong ung.
